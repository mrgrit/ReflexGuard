# 통합 시험 보고서 — 0.7.0

2026-09-25. 개발 VM Ubuntu 22.04 / Python 3.10 / Webots R2025a와 외부 Thor Ubuntu 24.04 / NVIDIA PyTorch 25.08을 사용했다. 실제 GPU와 mock을 각각 끝까지 실행했다. 원문: [실제 모델](logs/phase7-real.json), [mock](logs/phase7-mock.json).

| 실제 모델 시나리오 | 시간 | 주행 거리 | 최소 거리 추정 | 충돌 | 뇌 실패 |
|---|---:|---:|---:|---:|---:|
| 정면 보행자 | 10.016s | 1.656m | 0.272m | 0 | 0 |
| 옆문 보행자 | 10.016s | 0.235m | 0.820m | 0 | 0 |
| 고정 장애물 | 10.016s | 0.484m | 0.820m | 0 | 0 |
| 무조작 | 3.008s | 0.003m | 0.820m | 0 | 0 |

무조작의 약 3mm는 초기 물리 안정화 이동이며 모터 출력과 개입 횟수는 0이다. 거리는 시나리오 형상으로 계산한 추정치다. 충돌 판정과 거리 측정은 시뮬레이션 평가용이고 인코더/제어 입력으로 쓰지 않는다. 전진 시험은 주행 거리 0.1m 미만이면 실패하며 통신 오류로 멈춘 시험도 통합 성공으로 인정하지 않는다.

- 실제 모델 최종 이미지 100회 dt_ms=50 계약 호출, mTLS 미제공 거부, Bearer 미제공 401, 방향 응답·출력 침묵 통과. 왕복 중앙값 40.65ms, 최대 54.29ms.
- 실제 TLS 바이트를 중계하는 시험 소켓만 끊었다. 0.6m/s→0.536→…→0으로 10스텝(시뮬레이션 320ms)에 감속했다. 정상 서버가 다시 보이더라도 중립 입력/재조종으로 자동 재출발하지 않았다.
- 실제 GPU 연결 상태에서 임시 HTTPS 관제 로그인→서명 원격 정지→Webots 모터 출력 0→로그 검증까지 통과했다. 약 0.312m 주행, 감사 16레코드, 체인 유효, 뇌/관제 실패 0회. 로그의 모델 버전도 malecns- 접두사로 확인했다.
- mock 동일 리허설도 통과했다. 실제 뇌 세션을 자동으로 mock으로 바꾸는 주행 중 fallback은 없다. 정지 후 프로필을 명시해 새 프로세스/세션으로 재시작하는 운영 정책이다.
- 같은 pytest 계약을 mock과 실제 API 구현 양쪽에 적용한다. 서명/가중치 변조, 신뢰키 교체, 잘못된 서명 그래프, 과대 NPY shape, symlink, 외부 침묵 ID, 세션 소유권·재전송·역할·큐·시간 제한을 시험한다.

GPU와 NumPy 수치 비교는 [성능 보고서](brain_perf.md)를 참조한다. 최종 컨테이너의 Python 3.12에서도 모델/공통 계약 테스트 25개가 통과했다. 최종 코드로 공식 원본을 다시 변환한 weights.npz는 배포본 SHA-256과 동일했다. 초기 input_gain=10은 너무 일찍 정지해 0.069m만 이동했고 실패로 남겼다. gain=2.5 보정 첫 시험에는 후반부 VPN 200ms timeout이 한 번 있었다. 최종 통합에서는 오류가 없었지만 장기 통신 신뢰성을 입증하지 않는다.

## 보안 게이트

검사 명령은 `scripts/security_check.sh`이며 Bandit, Semgrep p/python, VM/GPU requirements pip-audit, 전체 pytest를 순서대로 실행한다. 실패 시 종료 코드 1이다. 최종 결과는 **Bandit 0건, Semgrep 151규칙/61파일 0건, VM/GPU 잠금 의존성 알려진 취약점 0건, pytest 280개 통과**다. 원문은 `logs/v0.7.0-security.log`에 기록한다. SBOM·버전·의존성·보안 매핑·실제 함수/테스트 존재 일치도 검사한다.

GPU 별도 잠금 감사는 NVIDIA vendor torch 개발 빌드나 컨테이너 OS 전체를 포함하지 않는다. pytest의 Starlette/httpx TestClient deprecation 경고는 기록하고 숨기지 않았다. Python 3.10과 현재 잠금 조합에서의 결과이며 GPU 컨테이너 전체 테스트를 대신하지 않는다.

## 재실행과 남은 범위

`scripts/e2e.sh real` 또는 `scripts/e2e.sh mock`을 실행하면 시험 로그를 `/tmp/reflexguard-e2e-*`에 보관하고 최종 JSON을 표준 출력에 쓴다. 정상 시나리오를 자동 재시도하여 오류를 숨기지 않는다. 기존 사용자의 서버나 다른 GPU 컨테이너를 종료하지 않는다.

사람의 실제 키보드/브라우저 조작 확인, 물리 휠체어 제동, 장애물/조명 다양화, 장기 부하, 실시간 watchdog은 별도 검증 대상이다. 이번 실제 모델의 세 월드는 위험 정지가 주된 회피 방식이다. 다음 버전에서 Jev 선택 정책의 진행률·불필요 정지·안전 검사를 비교한다. Phase 8 Attack Lab은 이번 범위에 포함하지 않는다.


## 0.8.0 회피·실시간 회로 확장 (2026-09-26)

위 표는 0.7.0의 정지 중심 회귀 기록이다. 0.8.0은 60m 복도, 4방향·두 높이 거리 스캔, 물체 이동 예측, 우회 후 사용자 진행 방향 복귀, 통합 설정, MaleCNS LIVE를 추가했다. 기본 2m/s 동적 트랙 시험에서 mock 54.693m, 실제 GPU·관제·Firefox 동시 실행 54.528m를 주행했고 둘 다 장애물 7개 통과·충돌/뇌/관제 오류 0이었다. 보행자 두 명의 최소 이동 거리는 29.952m로 확인했다.

무제한 3m/s 접근은 접촉해 거부했다. 장애물·측벽 6m 이내 2m/s 이하로 감속하는 최종 후보는 3m/s 요청에도 54.945m·7개 통과·충돌 0이었다. 기본 속도는 2m/s다. 실제 브라우저에서 187개 노드·185개 간선·95개 발화 뉴런 색 반영과 PC/모바일 폭 렌더링을 검사했다.

최종 보안 게이트 **338개 테스트 통과, Bandit·Semgrep·VM/GPU pip-audit 0건**. SBOM/버전/배포 해시/보안 매핑 검사를 포함한다. mock 기존 복도·무조작·단절·관제·감사 회귀도 통과했다. 원문은 `logs/v0.8.0-security.log`, `logs/v0.8.0-e2e-mock.json`이다.

이전 후보의 보행자 이름 중복으로 정지했던 시험은 정적 조건으로 정정했다. 실제 GPU 통신은 간헐적 200ms 초과가 여전히 발생하며 실패 시 정지 고정을 유지한다. 성공 실행만으로 장기 신뢰성을 주장하지 않는다. 실패·수정·최종 증거와 재현 조건은 [시연 보고서](demo_report.md)에 함께 보존한다.

실제 GPU 최종 배포에서도 복도 3종·무조작·단절 후 정지 고정·서명 원격 정지·감사 체인 통합을 통과했다. 증거는 `logs/v0.8.0-e2e-real.json`이다. 이전의 간헐적 200ms 실패 기록은 보존한다.

원격 정지 통합은 기본 복도에서 실제 전진 출력을 차단해야 통과하도록 강화했다. `remote_interventions > 0`과 최종 출력 0, 서명 확인, 감사 체인을 mock·실제 GPU 모두 검사한다. 추가 증거: `logs/v0.8.0-moving-stop-mock.json`, `logs/v0.8.0-moving-stop-real.json`.


## 0.8.1 연결·속도·화면 보정 (2026-09-26)

기본 요청 속도를 2→4m/s, 설정·시연 모터 상한을 3→6m/s로 올렸다. 기본 감속도에서는 열린 직선도 최대 4m/s이며 장애물 근처/회피 중에는 2m/s 이하로 낮춘다. 실제 로그의 최대 전진 명령은 4m/s다. 6m/s는 모든 구간의 실제 주행 속도를 뜻하지 않는다.

기존 배치의 첫 4m/s 시험은 충돌 없이 약 19.677m에서 진행이 막혔다(`logs/v0.8.1-demo-stalled.json`). 후속 박스 B/C를 각각 y=-2m/+2m로 옮겨 우회 공간을 확보했다. 최종 60초 local 시험은 54.582m·장애물 7개·복귀 2회·접촉/뇌 오류 0이었다(`logs/v0.8.1-demo-local.json`). 두 보행자 최소 이동은 29.952m다. 최소 거리 추정 0은 거친 지표이며 실제 접촉 이벤트 0과 구별한다. 자유 조종이나 모든 설정 조합의 무충돌 보증은 아니다.

SSH 터널 소멸은 사용자 서비스로 복구했으나 외부 GPU의 간헐적 200ms 초과는 남았다. GUI는 동일한 서명된 187개 MaleCNS 뉴런/185개 연결 LIF를 로컬 NumPy에서 실행한다. mock이나 실행 중 자동 대체가 아니다. 시작 전 mTLS health를 확인하고 화면에 LOCAL CPU/REMOTE GPU를 구분한다. 통신 실패 시 정지 고정은 유지한다. [연결 안내](brain_connection.md).

전후방 카메라를 하단에 축소하고 상공 구간 영상 3개는 기본 숨김으로 바꿨다. 기존 배치는 `scripts/configure_webots.py --reset-camera-layout`으로 카메라 항목만 재설정할 수 있다.

실제 HTTPS 관제·Firefox 동시 실행도 60초 54.582m·7개 통과·뇌/관제 오류 0으로 통과했다. 187개 노드·185개 간선, 발화 뉴런 92개의 색 반영, PC/모바일 가로 넘침 없음을 확인했다(`logs/v0.8.1-browser.log`, `logs/v0.8.1-demo-local-control.json`). 카메라 렌더링 시험은 중앙 지도에 상공 영상이 겹치지 않고 전후방 영상만 하단에 작게 표시됨을 확인했다. 렌더링 시험은 mock으로, 주행·LIVE 시험은 서명된 실제 local MaleCNS로 구분했다.

`scripts/e2e.sh local`은 복도 3종·무입력·통신 단절 후 정지 고정·인증 계약·실제 주행 중 서명 원격 정지·감사 체인까지 통과했다(`logs/v0.8.1-e2e-local.json`).

0.8.1 최종 품질 게이트: Bandit·Semgrep(151규칙/68파일)·VM/GPU pip-audit 0건, pytest 356개 통과. 증거: `logs/v0.8.1-security.log`. Starlette/httpx의 기존 deprecation 경고 1건은 유지했다. GUI를 local로 다시 열어 인증된 MaleCNS 상태와 입력 대기를 확인했다.
