# 현재 개발 계획 — MaleCNS 기준

초기 단계별 프롬프트는 초안이며, 사용자 변경 지시와 이 계획이 우선한다.
커넥톰·뉴런 주석·전달물질·연결 데이터는 동일한 MaleCNS v1.0 릴리스를 기준으로 한다.
뇌 시뮬레이션 코드는 데이터에 맞게 설계하고, 기존 특정 저장소의 모델이나 사전 가중치를 전제로 삼지 않는다.

| 단계 | 상태와 범위 |
|---|---|
| 환경 / Phase 0 | 개발 VM·부트스트랩 완료. GPU 장비 설치는 별도. |
| API / Phase 1 | mTLS mock·클라이언트 완료. 계약은 실제 MaleCNS 서버에도 적용. |
| 시뮬레이터 / Phase 2 | 휠체어·복도 3종 완료. |
| 공유 제어 / Phase 3 | 인코더·디코더·안전 정지·mock 통합. 결과와 한계는 calibration.md. |
| 관제 / Phase 4 | 로그인·역할·서명 원격 정지·판단 로그·대시보드 구현. 검증·실행은 phase4.md. 데이터 출처는 MaleCNS, 현재 mock 표시는 분리. |
| 보안 문서 / Phase 5 | STRIDE·KISA 테스트 매핑·SBOM·코드/데이터 라이선스 고지 예정. |
| 실제 모델 / Phase 6 | 아래 MaleCNS 구현 계획으로 대체. |
| 통합 / Phase 7 | mock/실제 서버 계약·3개 월드·통신 단절·보안 게이트·로그 검증. 대체 서버 전환 정책은 정지 후 재무장 조건까지 설계. |
| 시연 Lab / Phase 8 | 별도 저장소. 제출용 저장소에는 취약 모드나 공격 코드를 넣지 않음. |

## Phase 6 구현 기준

- GPU 장비의 OS·아키텍처·CUDA·메모리를 확인하고 호환 PyTorch를 설치·고정한다.
- `config/malecns.json`과 공식 배포 안내로 필요한 자료를 가져오고 [데이터 처리 설계](malecns.md)를 따른다.
- 실제 Feather 스키마와 값에 근거해 후보 뉴런을 선별한다. 양측 시각 입력과 하강 출력의 매핑 및 불확실성을 `docs/neurons.md`에 기록한다.
- 연결 가중치를 안전한 형식으로 변환하고, SHA-256과 배포자 서명 검증을 거치는 로더를 만든다. 형식 변환과 데이터셋 검증을 생략하지 않는다.
- 세션별 LIF 상태, 자원·시간·동시 세션 제한, 큐, mTLS와 Bearer 인증, 서명된 침묵 허용목록을 구현한다.
- 입력 강도·발화율 정규화와 공유 제어 임계값을 실제 모델로 다시 보정한다. mock 보정값이 그대로 적합하다고 가정하지 않는다.
- 공통 API 계약 시험과 50ms step 성능을 검증하고, VM에서 실제 서버로 복도 3종을 실행한다.
- 결과가 기준을 충족하기 전에는 UI·문서에서 실제 모델 동작 완료로 표현하지 않는다.
