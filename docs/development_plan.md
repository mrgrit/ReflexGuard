# 현재 개발 계획 — MaleCNS 기준

초기 단계별 프롬프트는 초안이며, 사용자 변경 지시와 이 계획이 우선한다.
커넥톰·뉴런 주석·전달물질·연결 데이터는 동일한 MaleCNS v1.0 릴리스를 기준으로 한다.
뇌 시뮬레이션 코드는 데이터에 맞게 설계하고, 기존 특정 저장소의 모델이나 사전 가중치를 전제로 삼지 않는다.

| 단계 | 상태와 범위 |
|---|---|
| 환경 / Phase 0 | 개발 VM·부트스트랩 완료. GPU 장비 설치는 별도. |
| API / Phase 1 | mTLS mock·클라이언트 완료. 계약은 실제 MaleCNS 서버에도 적용. |
| 시뮬레이터 / Phase 2 | 휠체어·검증 복도 3종 + 0.8.0 긴 시연 복도. |
| 공유 제어 / Phase 3 | 인코더·디코더·안전 정지·mock 통합. 결과와 한계는 calibration.md. |
| 관제 / Phase 4 | 0.8.0 운영자 주행 설정·재시작 적용. 로그인·역할·서명 원격 정지·판단 로그·대시보드 구현. 검증·실행은 phase4.md. 데이터 출처는 MaleCNS, 현재 mock 표시는 분리. |
| 보안 문서 / Phase 5 | STRIDE·KISA 27개 항목/테스트 매핑·Python 환경 SBOM·라이선스 고지 완료. 적용 범위·제한·검증은 phase5.md. |

| 통합 / Phase 7 | 0.7.0 완료: mock/실제 서버 계약·3개 월드·무조작·통신 단절·관제/로그 리허설. 정지 후 명시적으로 프로필을 선택해 새 세션 시작. test_report.md 참조. |

## Phase 6 구현 기준

- GPU 장비의 OS·아키텍처·CUDA·메모리를 확인하고 호환 PyTorch를 설치·고정한다.
- `config/malecns.json`과 공식 배포 안내로 필요한 자료를 가져오고 [데이터 처리 설계](malecns.md)를 따른다.
- 실제 Feather 스키마와 값에 근거해 후보 뉴런을 선별한다. 양측 시각 입력과 하강 출력의 매핑 및 불확실성을 `docs/neurons.md`에 기록한다.
- 연결 가중치를 안전한 형식으로 변환하고, SHA-256과 배포자 서명 검증을 거치는 로더를 만든다. 형식 변환과 데이터셋 검증을 생략하지 않는다.
- 세션별 LIF 상태, 자원·시간·동시 세션 제한, 큐, mTLS와 Bearer 인증, 서명된 침묵 허용목록을 구현한다.
- 입력 강도·발화율 정규화와 공유 제어 임계값을 실제 모델로 다시 보정한다. mock 보정값이 그대로 적합하다고 가정하지 않는다.
- 공통 API 계약 시험과 50ms step 성능을 검증하고, VM에서 실제 서버로 복도 3종을 실행한다.
- 결과가 기준을 충족하기 전에는 UI·문서에서 실제 모델 동작 완료로 표현하지 않는다.

0.4.1: 로컬 관리자 비밀번호 복구 도구·잠금 해제·세션 폐기와 로그인 안내를 보완했다. 이후 Phase 5 문서 작업에 반영했다.

0.5.0: 보안 문서와 SBOM을 작성하고 문서/함수/테스트/잠금 파일 일치 검사를 추가했다. 다음 Phase 6은 외부 GPU 장비가 필요하며 아직 실행하지 않았다.

0.5.1: 외부 Jetson Thor 환경 준비와 다이제스트 고정 GPU 부트스트랩을 추가했다. 실제 모델 구현·성능·Webots 검증은 남아 있다. 세부 증거와 제한은 [GPU 환경](gpu_environment.md)에 기록한다.

0.7.0: 실제 MaleCNS GPU와 mock 통합 리허설을 완료했다. 첫 시뮬레이션 버전의 자동 검증 결과이며 실제 장비 검증은 별도다.

## 첫 버전 완료 후: Jev 행동 선택 확장 (다음 버전)

사용자 요청(2026-09-25): 첫 버전을 완료·검증한 다음 Jev를 이용한 다중 행동 선택을 추가한다. 현재 Phase 6의 완료 범위에 이 기능을 섞지 않는다.

- 후보: 사용자 명령 유지, 감속, 정지, 좌회피, 우회피. 주행 가능 공간·충돌 예상·속도·사용자 의도를 기준으로 안전한 후보만 남긴 뒤 Jev가 하나를 선택한다.
- Jev의 구체적 모델/제품·API와 입력 계약은 다음 버전 설계 착수 시 확정한다. 지금은 이름만으로 아키텍처를 추정하지 않는다.
- 별도의 결정적 안전 검사기가 선택 결과를 재검증한다. 위험한 조향, 권한 없는 명령, 역방향/급격한 가속을 거부한다. 안전 후보 없음·시간 초과·통신 장애에는 안전 정지한다.
- 정지 일변도를 줄이는 지표: 충돌 0회 조건 아래 경로 진행률, 불필요한 정지 횟수, 사용자 개입/조향 변화, 회피 후 복귀와 처리 지연을 첫 버전과 비교한다.
- 검증 시나리오: 정면 보행자·옆문 보행자·고정 장애물, 좌/우 통로 차단, 양쪽 차단, 무조작, 통신 단절, 선택 결과의 시간 만료·위조·재전송.
- 완료 기준: 첫 버전 리허설 완료 이후 착수. 안전 검사 및 실패 시 정지 테스트를 통과하고, 동일 조건에서 불필요한 정지를 줄이는 결과가 있어야 다음 버전 완료로 표시한다.

## 0.8.0 시연 개선

60m 트랙·기본 2m/s/상한 3m/s·다중 카메라·거리 기반 우회와 방향 복귀·통합 설정을 추가했다. MaleCNS LIVE는 실제 187개 계산 발화율을 표시한다. 신경 위험 출력과 로컬 경로 선택의 역할을 분리한다. 최신 성공·실패 시험은 demo_report.md에 기록한다. 전체 발화율은 500ms 간격으로 전송한다. 보행자 이름 중복으로 이동하지 않았던 이전 시험은 정적 조건으로 정정했으며, 최종 시험은 각 보행자 이동 거리도 검사한다. 이전 시험에서는 200ms 시간 초과가 반복됐으므로 VPN·VM 장기 지연 보장은 별도다. Jev 행동 선택은 별도 후속 버전이다.

최종 동적 60초 시험은 mock·실제 GPU/관제/Firefox 모두 7개 장애물 통과·충돌/통신 오류 0으로 통과했다. 상한 3m/s 요청은 장애물 6m 이내에서 2m/s 이하로 제한한 조건에서 통과했다. 보안 게이트는 338개 테스트 통과다.
