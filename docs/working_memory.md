# ReflexGuard 지속 작업 메모리

갱신: 2026-09-26. 저장소 `AGENTS.md`가 세션 시작 시 이 파일을 읽도록 지정한다. 비밀번호·토큰은 저장하지 않는다.

## 사용자 상시 승인과 선호

- 사용자는 여러 차례 **설치·프로그램/스크립트 실행·수정·테스트·git add/commit/push를 매번 묻지 말고 자율 진행**하라고 명시했다. 실행할지, 커밋할지, 푸시할지 다시 질문하지 않는다.
- 이 컴퓨터는 개발용 빈 환경이며 개발 환경 설치/서비스 실행에 적극적으로 진행하라는 지시가 있다. 그래도 작업과 무관한 삭제나 비밀 공개 권한으로 확대 해석하지 않는다.
- 한 단계가 끝나도 이미 요청한 후속 작업이 남으면 답변을 기다리지 않고 진행한다. 선택 가능한 구현 세부사항은 합리적으로 결정한다.
- 필수 샌드박스 승인은 사용자 선호로 해제되지 않는다. 이미 승인된 명령을 우선 사용하고, 필요한 필수 도구 승인을 별도의 대화 확인 질문으로 반복하지 않는다. 승인 우회는 하지 않는다.
- 버전이 바뀔 때 README·CHANGELOG·관련 내부 문서와 검증 결과를 함께 갱신한다. 커밋 메시지는 한국어로 무엇을/왜 바꿨는지 쓴다.
- 커넥톰 기준은 **MaleCNS**다. 초기 프롬프트의 데이터 소스 계획은 변경되었다.

## 현재 진행 중인 요청

- 관제에서 속도·루밍·정지/조향 임계값을 관리하고 재시작 때 적용. 역할/CSRF/범위/동시 수정 검증 및 기본값 복원.
- 짧은 시연을 개선하기 위해 60m 트랙, 다양한 장애물·횡단 보행자·좁은 통로, 전후방/구간별 관람 카메라.
- 시연 속도 기본 2.0m/s, 상한 3.0m/s를 시험. 기존 회귀 월드 상한은 보존.
- 정지만 하지 않고 빈 공간으로 우회하고 사용자 조종으로 복귀. MaleCNS 위험 출력과 로컬 거리 기반 회피의 역할을 구분해 표시. 장애/막힘 시 정지 유지.
- 모든 조종/상황에서 무충돌을 보장한다고 주장하지 않는다. 실제 시험에서 관측한 결과와 실패 후보를 기록한다.
- Jev 기반 행동 후보 선택은 별도 후속 버전 계획이며 지금의 거리 기반 회피와 혼동하지 않는다.

검증 전인 실험을 완료 상태로 기록하지 않는다. 정확한 코드/실행 상태는 git diff, 테스트 로그와 현재 대화 인계 내용을 함께 확인한다.

- 0.8.0 MaleCNS LIVE: 실제 187개 발화율·185연결, mock/지연 구분. 최신 검증과 남은 GPU/VPN 지연은 docs/demo_report.md를 읽는다.
- 도구 실행 시 파일 작성과 실행을 한 명령에 섞거나 승인된 SSH 명령 안에 복잡한 Python 인라인 코드를 넣으면 기존 승인 규칙과 매칭되지 않을 수 있다. 파일 수정과 실행을 분리하고 단순한 기존 승인 명령을 사용한다. 플랫폼 필수 승인을 우회하지 않는다.

## 0.8.0 마무리 상태

- 실제 GPU·관제·Firefox 동적 60초 시험: 54.528m, 7개 통과, 복귀 2회, 충돌/뇌/관제 오류 0. 187개 회로 노드와 발화 색 반영 확인.
- 보행자 이름 중복으로 움직이지 않았던 옛 시험은 정적 조건으로 정정했다. 완료 검사는 두 보행자 실제 이동도 검사한다.
- 3m/s 무제한 접근은 접촉해 거부했고, 장애물/측벽 6m 이내 2m/s 제한 후 3m/s 요청 시험은 통과했다. 기본 2m/s.
- 실제 GPU 시험에서 간헐적 200ms 지연은 여전히 관측된다. 실패 시 정지 고정을 유지하고 성공·실패 모두 docs/demo_report.md에 남긴다.
- Jev 선택 정책과 별도 Attack Lab은 이번 0.8.0에 구현하지 않았다.
