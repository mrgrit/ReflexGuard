# MaleCNS LIVE — 0.8.0

관제 로그인 → 각 장치의 **MaleCNS 실시간 신경회로 보기**. 기본 장치 주소는 `https://localhost:8444/activity/seat-a`다. Webots를 실제 뇌 프로필로 실행하면 기존 관제 보고에 뉴런 발화율이 함께 전달된다.

- MaleCNS v1.0 LPLC2 185개(L94/R91), DNp01 2개, 연결 185개·원본 시냅스 4,862개. 전체 뇌가 아닌 축소 LIF 회로다.
- 점은 실제 뉴런 ID에 대응한다. 색은 최신 step 구간의 시뮬레이션 발화율이며 생체 측정값이나 스파이크별 애니메이션이 아니다. 클릭·키보드 초점으로 ID/유형/좌우/Hz를 확인한다.
- 선은 실제 연결이며 두께는 원본 시냅스 수를 나타낸다. 배치는 설명을 위한 회로도이며 해부학적 좌표가 아니다.
- 좌우 루밍, 두 DNp01 출력, escape, 최종 주행 판단·속도, 최근 60개 수신 위험 출력 샘플을 표시한다. 전체 뉴런 배열은 뇌 서버에서 약 500ms마다 샘플링하고 클라이언트가 다음 샘플까지 보관한다. 신경 발화율은 표시된 최신 주행 시각보다 최대 약 500ms 이전 샘플일 수 있다. 위험 출력·상위 뉴런은 매 step마다 갱신한다. 제어기 보고 주기는 시뮬레이션 약 500ms 및 안전 정지 상태 변경 시점, 브라우저 조회는 벽시계 500ms다. 모든 32ms step을 기록/표시하지 않는다.
- 동일 모델 버전·가중치 SHA-256·187개 ID/유형 일치 시에만 `LIVE · MaleCNS 모델 일치`로 표시한다. 이는 인증된 장치가 보고한 모델 식별값의 일치이며 원격 하드웨어 증명은 아니다.
- mock, 모델 불일치, 2초 초과 지연, 연결 끊김에는 실제 뉴런 색을 회색으로 지운다. 미수신을 0Hz로 표시하지 않는다. 관제 서버/장치 세션 재시작 시 이력은 초기화된다.

전체 발화율은 장치별 최신 프레임 하나만 메모리에 두며, 이력은 60개 요약으로 제한한다. DB 감사 체인은 기존 상위 뉴런만 보존하여 전체 프레임으로 로그가 불어나지 않는다. 새 조회 API는 기존 세션·보호자 장치 소유권을 검사한다. 시각화 조회는 읽기 전용이며 제어기에 명령을 보내지 않는다. 관제 보고 경로 자체의 기존 실패 정지 정책은 유지된다.

`StepResponse.neuron_activity`와 `DecisionInput.neuron_activity/weights_sha256`를 추가했다. 기존 엄격한 클라이언트는 알 수 없는 필드를 거부하므로 서버·클라이언트를 함께 갱신한다. HTTP 본문 상한은 그대로 유지한다. 현재 187개 프레임은 32KiB 관제 한도 이하다.

그래프 재생성은 신뢰된 배포 환경의 `REFLEXGUARD_MODEL_DIR`, `REFLEXGUARD_MODEL_PUBLIC_KEY`를 설정하고 `PYTHONPATH=src:. .venv/bin/python scripts/export_circuit_graph.py`로 수행한다. `load_assets`가 서명·SHA-256을 검사한 다음 공개 메타데이터만 만든다. 자산 디렉터리에서 발견한 키를 임의로 신뢰하면 안 된다. 최초 생성은 기존 배포 provenance의 공개키 해시와 대조했다.
